Implementation approach

One dataset, two deliberate readings.

Desktop renders the entries as five editorial day columns. Smaller screens use the same ordered data as a day-by-day agenda with details opening inline. Category labels remain visible throughout, while colour works as a secondary cue.

Selection is persistent, explicit connections are marked in text and every interaction is available by touch or keyboard. The full data model and editorial notes sit in the accompanying implementation file.
