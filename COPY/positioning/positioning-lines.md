# Positioning lines

Undated brainstorm, generated before the interviews and before the sentence-opener rule was written
down. Moved here from `COPY/resume-website-positioning-lines.md` (repo root) 17 August 2026.

**Status: Available.** Not placed anywhere on the site. Brad's ruling, 17 August 2026: *"these lines
are in the right direction but should not all start with 'I'."* The original had 74 lines, 43 of them
(58%) opening with "I" — a breach of the sentence-opener rule at
`COPY/perplexity-copy-brief.md`§3 ("do not start more than two of N lines with the same word"),
scaled up: no set below carries more than two "I"-openers.

**What changed in the re-cut.** Sections are unchanged; lines are cut, not rewritten — the words are
Brad's original phrasing throughout, this pass only removes redundancy and re-sequences each set so
no opener repeats more than twice. 74 lines cut to 44. Cuts were near-duplicates within a section
(three or four lines making the same point in the same shape) and lines that fail the value test at
`COPY/perplexity-copy-brief.md` ("cover the company, the dates and the title — does it still tell a
buyer what they get?"). Nothing cut is unique; the idea survives in a kept line from the same section.
The full 74-line original was never committed to git (it sat untracked at repo root); every line
from it that carried a distinct idea survives somewhere in this file, either kept as-is or as the
idea behind a kept line in the same section.

**The SaaS fence.** Several kept lines below name SaaS specifically. That is fine for this file — it
is raw material for different reader framings, and a recruiter-facing set narrowed to SaaS is a
legitimate variant to have on hand. It is **not** fine for the hero or any broad-reader page: Brad
ruled the hero must be broader than one industry (`COPY/hero-lines/hero-lines.md` round eight,
constraint 4). Treat every SaaS-specific line here as scoped to a SaaS-reader context only, never as
a default.

**Not scored against the interview claims register.** These lines predate `_claims-register.md` and
are pitched, not cited — none of the "cite or die" discipline in `hero-lines.md` round five applies
here. Useful as raw phrasing to pull from, not as finished, evidence-backed copy.
