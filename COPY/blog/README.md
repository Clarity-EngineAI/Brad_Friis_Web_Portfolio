# COPY/blog — the blog

Created 15 August 2026 with the first two row-four drafts. This is the `field-notes/` folder
predicted in `COPY/README.md`, renamed because **Brad calls it the blog.**

## What is different about this folder

**The blog is not written in the §7 voice.** Its spec is `design/09-blog-voice.md`, not §7 of
`design/01-positioning-brief.md`, and the direction of work is inverted: for every other folder in
`COPY/`, an agent drafts and Brad chooses. **For the blog, Brad writes and §4 of the voice spec
checks afterwards.**

The two drafts currently here are the exception that proves it — they are row-four posts drafted from
interview material Brad supplied specifically for that purpose, because the stories predate the blog.
**Posts Brad writes himself do not get drafted here. They get reviewed here.**

Everything else about `COPY/` applies unchanged: four statuses, an argument for and an argument
against every decision, dated status changes, nothing deleted when it loses a round.

## The two style examples

Moved here from `COPY/career/` on 15 August 2026, per `design/09-blog-voice.md` §7. `career/` is the
career-record folder and fiction samples sitting in it were a filing error waiting to be mistaken for
approved career copy.

**They are reference material, not copy.** They are Brad's own writing, tabled as the spec for the
row-four register. They carry no status because they are not candidates for any slot on the site.

**`design/09-blog-voice.md` §3.1 is explicit that these examples are the better spec** — read them
before drafting any row-four post and prefer them over any prose description of the register,
including §3.1 itself.

## Before any post publishes

Run `design/09-blog-voice.md` §4 over the finished draft. It produces flags, not rewrites. Hard stops
in §4.1 block; everything else goes to Brad. **When Brad overrules a flag, record the overrule here as
an argument-against and publish** — a style flag is never a veto.
