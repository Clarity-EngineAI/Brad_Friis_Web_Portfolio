## Evidence status vocabulary

Parallel to, and distinct from, the copy statuses in `COPY/README.md`. Those describe copy; these
describe whether a fact was measured.

| Status | Meaning |
| --- | --- |
| **Measured** | A figure exists and Brad can source it. Publishable as a number. |
| **Retrievable** | Measured once; number not to hand. Records who or what would have it. |
| **Vouched** | No figure, but a named person would confirm it, in writing if asked. |
| **Unevidenced** | Happened, nothing to support it. Not publishable as a claim. |
| **Never** | Did not happen. Recorded so the ground is not covered again. |

Every claim also carries **publishable: yes / no**. Where a claim is true, evidenced and
unpublishable, the anonymised publishable form is written directly underneath it.
