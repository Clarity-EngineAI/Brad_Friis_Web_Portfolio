# COPY — the writing library

Every line of copy written for this site that is worth keeping lands here, whether or not it is
currently in use. Nothing is deleted when it loses a round. A line rejected for the hero is often
the right line for a section heading three screens down, and a line that reads wrong in August
may read right in October.

Brad chooses. The job of this folder is to make sure the choice is always available.

## Structure

```
COPY/
├── README.md              this file
├── hero-lines/            display lines for the top of a page
│   └── hero-lines.md
├── letters/               the /letters page — headline, captions, pull-quotes, blocks
│   └── letters-page.md
├── navigation/            nav labels, page headlines, glosses, the CV button
│   └── navigation.md
└── section-headings/      headings, eyebrows, captions and calls to action
    └── section-headings.md
```

Folders are added as new categories of copy appear. `letters/` replaces the `proof/` folder predicted
here, along with the route. Still likely: `record/` for the career page, `cv/` for the four variant
summaries, and `field-notes/` for article titles and standfirsts.

## Status key

Every entry carries one of four statuses.

| Status | Meaning |
| --- | --- |
| **In use** | Currently placed on the site. The file says where. |
| **Available** | Written, holds up, not currently placed. Ready to swap in. |
| **Held** | Deliberately reserved for a specific slot elsewhere on the site. |
| **Rejected** | Turned down by Brad, kept for the record so the same ground is not covered twice. |

## Rules for entries

- Every option carries the argument for it **and** the argument against it. An option with no
  stated cost has not been thought about properly.
- Support copy is stored with its display line, because the two are judged together.
- New Zealand English. The banned-words list is section 7 of `design/01-positioning-brief.md`.
- Date every status change. Copy decisions get revisited and the reasoning matters more than
  the verdict.
